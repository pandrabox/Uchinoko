# Uchinoko for Palworld 사용법 — VRChat 아바타 편

*[日本語](manual.md) | [English](manual.en.md) | [繁體中文](manual.zh-TW.md) | [简体中文](manual.zh-CN.md)*

## 아바타 사용법
자신의 아바타 Unity 프로젝트를 엽니다(Unity 2022.3.22f1에서 동작합니다).
![](img/2.webp)

Hierarchy에 있는 자신의 아바타를 드래그하여 Assets 바로 아래에 드롭합니다(프리팹으로 만들어집니다).
![](img/3.webp)

드래그로 생성된 아이콘을 마우스 오른쪽 버튼으로 클릭하고 "Show in Explorer"를 실행합니다.
**Unity를 종료**합니다.
![](img/4.webp)

Uchinoko for Palworld(Uchinoko.bat)을 더블클릭하여 엽니다. 처음 실행할 때 "게시자를 확인할 수 없습니다" 같은 경고가 표시될 수 있지만, "열기"(또는 "실행")를 선택하여 실행해도 문제없습니다.
![](img/1.webp)

**처음 실행할 때만**, 변환에 필요한 Blender(약 350MB)를 화면 뒤에서 자동으로 다운로드합니다(대화 상자는 표시되지 않습니다). 준비가 끝날 때까지 화면 하단에 "준비 중" 표시가 나타나며, "전체 변환" 등의 버튼은 누를 수 없습니다. 회선 환경에 따라 몇 분 정도 걸릴 수 있지만, **그대로 기다려주세요**. 준비가 끝나기 전에 드래그 앤 드롭해도, 준비가 완료되면 자동으로 처리됩니다. 잘 되지 않을 때는 아래의 "문제가 발생했을 때"를 참조해주세요.

탐색기에서 자신의 아바타 prefab을 Uchinoko for Palworld로 드래그 앤 드롭합니다.
![](img/5.webp)

잠시 기다립니다.
![](img/6.webp)

썸네일이 표시되고 "전체 변환(모드 생성)"을 누를 수 있게 되면 누릅니다.
![](img/7.webp)

이용약관이 표시되므로 내용을 확인한 후 동의해주세요.
![](img/8.webp)

잠시 기다리면 적용이 완료됩니다(팰월드는 종료해두세요).
![](img/9.webp)


## 문제가 발생했을 때: 초기 설정(Blender 다운로드)에 실패하는 경우

인터넷 연결 문제 등으로 최초 실행 시 Blender 자동 다운로드가 실패하는 경우가 있습니다. 드래그 앤 드롭을 해도 불러오기가 완료되지 않거나 오류로 멈추는 경우, 먼저 이 문제를 의심해보세요.

1. 인터넷 연결을 확인한 후, Uchinoko for Palworld를 재시작하거나 화면 오른쪽 아래의 "Blender 다시 받기" 버튼을 눌러주세요.
2. 그래도 실패하는 경우, 수동으로 준비할 수 있습니다.
   1. https://www.blender.org/download/ 에서 Blender 4.3.2의 Windows x64판(Portable/zip)을 다운로드합니다.
   2. 다운로드한 zip을 압축 해제하고, `blender.exe`가 있는 폴더의 내용을, Uchinoko.bat과 같은 위치에 있는 `res\assets\tools\blender-4.3.2-windows-x64\` 폴더 안에 그대로 복사합니다(폴더가 없으면 새로 만들어주세요. **v2.2.x 이전 구버전에서는 이 폴더가 실행 파일과 같은 위치의 `assets\tools\blender-4.3.2-windows-x64\` 또는 `_internal\assets\tools\blender-4.3.2-windows-x64\`에 있습니다**).


## Tips

- 본 변환 도구는 개인이 자신의 아바타로 즐기기 위한 것입니다. 멀티플레이 등은 지원하지 않습니다.
- 다른 pak MOD와의 병용은 지원하지 않습니다. 다른 pak MOD가 감지되면 경고가 표시됩니다.
- 오른쪽 아래 메뉴에서 다양한 작업을 할 수 있습니다.
  - 팰월드에 적용… 여러 개를 변환해서 전환하고 싶을 때나, 변환이 완료되었을 때 팰월드가 실행 중이어서 제대로 적용되지 않았을 때
  - 모드 해제… 해제하고 싶을 때
  - 목록 새로고침… 모드 목록을 새로고침
  - 변환 결과 삭제… 필요 없어진 캐릭터를 삭제하고 싶을 때
  - 문의하기… 문제가 생겼을 때
  - 로그 수동 복사… 문의할 때 함께 첨부해주시면 지원에 도움이 됩니다.
